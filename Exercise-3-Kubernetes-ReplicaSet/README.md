# Exercise 3: Kubernetes ReplicaSet

## Objective
Deploy and scale a flash-sale application using a Kubernetes ReplicaSet.

## Tasks Completed
- Built and deployed a Flask application.
- Configured a ReplicaSet and ClusterIP Service.
- Configured readiness and liveness probes.
- Scaled the ReplicaSet from three to five replicas.
- Tested the application endpoints and self-healing behavior.

## Technologies
Kubernetes, Minikube, Docker, Python, Flask
