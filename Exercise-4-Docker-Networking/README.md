# Exercise 4: Docker Networking

## Objective
Configure communication between multiple containers using a custom Docker bridge network.

## Tasks Completed
- Created the `my-bridge-net` bridge network.
- Built a Flask REST API image.
- Started Flask, MySQL, and Redis containers on the same network.
- Verified container-name resolution and connectivity using ping.
- Tested the Flask `/about` endpoint.

## Technologies
Docker, Python, Flask, MySQL, Redis
