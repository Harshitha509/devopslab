# Exercise 1: Kubernetes Hello Pod

## Objective
Deploy an Nginx application on Kubernetes using Minikube and access it through a NodePort Service.

## Tasks Completed
- Started a local Kubernetes cluster using Minikube.
- Created the `hello-k8s` Pod using the Nginx image.
- Verified the Pod status using `kubectl get pods`.
- Exposed the Pod using a NodePort Service.
- Opened the Nginx welcome page using `minikube service hello-k8s`.

## Technologies
Kubernetes, Minikube, Docker, Nginx
