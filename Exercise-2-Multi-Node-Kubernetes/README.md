# Exercise 2: Multi-Node Kubernetes

## Objective
Deploy and test containerized Flask applications across a multi-node Minikube cluster.

## Tasks Completed
- Created a three-node Minikube cluster.
- Built and loaded Flask application images.
- Deployed Product Catalog and Shopping Cart applications.
- Configured Deployments, pod anti-affinity, and NodePort Services.
- Tested application endpoints.

## Technologies
Kubernetes, Minikube, Docker, Python, Flask
