# Exercise 5: Docker Security with AppArmor

## Objective
Explore Docker container security and AppArmor profile configuration using Python.

## Tasks Completed
- Built and tested a Flask Docker image.
- Installed the Docker SDK for Python.
- Created scripts to inspect container security options and test restricted actions.
- Investigated AppArmor availability in the Docker Desktop environment.

## Environment Limitation
AppArmor enforcement was unavailable in the tested Docker Desktop environment. The requested profile option was recorded by Docker, but restricted-action tests succeeded. Actual AppArmor enforcement was therefore not demonstrated.

## Technologies
Docker, Python, Flask, Docker SDK, AppArmor
